## ⚡ Overview

This repository houses the source code for Mayank Yadav's Founder Digital HQ (`itsmayank.me`). Built with a high-performance, zero-dependency, motion-rich vanilla architecture featuring:

- **Cinematic Obsidian Space Aesthetics**: Custom dark design system with violet/cyan neon accents and glassmorphism.
- **2D Physics & Dynamic Interactions**: Magnetic character typography, radial hover spotlight sheen, interactive 3D card tilt, and multi-layer context cursor.
- **Web3 Digital Identity**: Verifiable cryptographic endpoints (Base ENS, EVM, Solana, BTC Taproot) with one-click checksum clipboard and Web Audio chime.
- **Hacker Shell & Command Palette (`⌘K` / `~`)**: Built-in interactive CLI terminal shell and keyboard navigation.
- **Production Resume Delivery Engine**: Dynamic fail-safe resume distribution system serving direct PDF streaming across static CDNs, serverless edge functions, and local runtime.

## 🛠️ Architecture & Tech Stack

- **Frontend**: Semantic HTML5, Modular Modern CSS (CSS custom properties, CSS Grid/Flexbox), Vanilla ES6+ JavaScript.
- **Backend / Delivery Engine**: Node.js HTTP Server (`server.js`) & Vercel Edge Serverless Functions (`/api/resume/*`).
- **Security**: Timing-safe scrypt cryptographic derivation, fail-closed superuser authentication, and strict sanitization.

## 🚀 Quick Start (Local Development)

### Prerequisites
- Node.js (v18 or higher recommended)

### Installation & Run
```bash
# Clone the repository
git clone https://github.com/mayankyadav89/portfolio.git
cd portfolio

# Start local server
node server.js
```

The application will be available at:
- **Founder HQ**: `http://localhost:3000`
- **Resume Dossier**: `http://localhost:3000/resume`
- **Direct PDF Download**: `http://localhost:3000/resume.pdf` or `http://localhost:3000/api/resume/download`
- **Admin Management**: `http://localhost:3000/admin`
