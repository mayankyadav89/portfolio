SVG AegisVault: Smart Account Architecture

Experimental hybrid smart account exploring passkey-based biometric authentication, Paymaster gas sponsorship, and modular security.

SVG AegisVault investigates how Account Abstraction (ERC-4337) and WebAuthn hardware enclaves eliminate the UX friction of Web3. By replacing fragile 24-word seed phrases with device-native biometric Passkeys and automated UserOperation bundlers, it showcases the future of consumer Web3 onboarding.

OVERVIEW

Overview & Motivation

Externally Owned Accounts (EOAs) like standard MetaMask accounts require users to manage private keys and seed phrases manually. Losing a seed phrase means total asset loss; signing malicious transactions drains accounts instantly; and users must always hold volatile native tokens (ETH) just to pay gas.

SVG AegisVault was built to test and demonstrate programmable smart accounts: transforming wallets into smart contracts that can enforce custom validation logic, multisig rules, social recovery, and gas sponsorship.

Instead of broadcasting a raw transaction directly, the user signs an off-chain `UserOperation` struct using their device's hardware enclave (TouchID / FaceID). Bundlers batch multiple UserOperations into a single on-chain transaction calling the universal `EntryPoint.sol` contract.

SECURITY

WebAuthn Passkey Security Architecture

Passkeys utilize the `secp256r1` (P-256) elliptic curve supported natively by Apple Secure Enclave, Android Keystore, and Windows Hello. SVG AegisVault verifies these hardware signatures directly on Base Sepolia using optimized modular precompiles, ensuring the private key never leaves user hardware.

GASLESS

Paymaster & Gas Sponsorship Model

A custom Verifying Paymaster smart contract is integrated to sponsor gas fees or permit payment in ERC-20 stablecoins (e.g. USDC), removing the necessity for users to acquire native testnet or mainnet ETH before interacting with applications.
